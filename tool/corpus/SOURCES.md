# Corpus sources & licences — So'z Jangi

Every data input used to build `answers.txt` and `valid_guesses.txt`, with its
licence and how it is used. The game is a **monetised** app (shop, ads, IAP), so
only sources whose licence permits **commercial** use are used. Non-commercial
(NC) and strong-copyleft (GPL) sources were explicitly evaluated and **rejected**
— see the bottom of this file.

## Inputs used

### 1. MUNIS Uzbek Latin Hunspell dictionary — **CC0-1.0** (public domain)
- **What:** `uz_Latn_UZ.dic` (75,538 stems, with `po:` part-of-speech tags) and
  `uz_Latn_UZ.aff`, the modern Uzbek Latin spellchecker produced by the
  "Modernizing Uzbekistan National Innovation System" (MUNIS) project (Grant
  REP-2/6, 2022–2024).
- **Source:** https://github.com/uzbek-spell/spellchecker (release `v1.0`)
  - `uz_Latn_UZ.dic` → https://github.com/uzbek-spell/spellchecker/releases/download/v1.0/uz_Latn_UZ.dic
  - `uz_Latn_UZ.aff` → https://github.com/uzbek-spell/spellchecker/releases/download/v1.0/uz_Latn_UZ.aff
  - Project site: https://uzbek-spell.github.io/
- **Licence:** CC0-1.0 — verified from the repository `LICENSE` file. Commercial
  use permitted, no attribution required (we attribute anyway, here).
- **How used:** the authoritative lexicon. Provides (a) the answer pool — its
  lowercase, well-formed, 5-logical-letter stems — and (b) the base for
  deterministically generated regular inflections in the valid-guess list. Its
  lack of proper nouns (verified: `toshkent`, `samarqand` absent; only one
  uppercase entry, the abbreviation `FHDYO`, which we drop) makes lexicon
  membership a reliable "real common word, not a name" signal.

### 2. Uzbek Wikipedia word frequencies — **CC BY-SA 4.0**
- **What:** `wiki_freq.tsv`, a word-frequency table we build ourselves by
  sampling article intros from Uzbek Wikipedia through the public MediaWiki API
  (`action=query&generator=random&prop=extracts`). Columns: `token`,
  `total_count`, `title_count`. Generated by `fetch_wiki_freq.py`.
- **Source:** https://uz.wikipedia.org (content © its authors, CC BY-SA 4.0)
- **Licence:** CC BY-SA 4.0. Commercial use permitted **with attribution +
  share-alike**. Attribution: "Word-frequency data derived from Uzbek Wikipedia
  (uz.wikipedia.org), licensed CC BY-SA 4.0." Any redistribution of the derived
  frequency table or the answer tiers must carry CC BY-SA 4.0.
- **How used:** (a) ranks answer candidates and splits them into 3 difficulty
  tiers (more frequent = easier); (b) admits common attested inflected word-forms
  into the valid-guess list; (c) drives the proper-noun heuristic
  (`title_count/total_count`). It is a **build input**, never shipped verbatim.
- **Why self-derived:** the convenient pre-built Uzbek frequency list (Leipzig
  Corpora Collection, `uzb_wikipedia_2021`) is released under CC BY-NC and is
  therefore unusable in a monetised app. Uzbek Wikipedia is the same underlying
  text under a commercial-friendly licence, so we sample it directly.

### 3. Offensive-word exclusion list — first-party (this repo)
- **What:** `exclusions/offensive_uz.txt`, a manually curated content-moderation
  blocklist (profanity, explicit sexual terms, strong slurs).
- **Licence:** authored here; no third-party rights.
- **How used:** removes matches from both `answers.txt` and `valid_guesses.txt`.

## Licence of the produced assets
Because the answer tiers and part of the valid-guess list are derived from CC
BY-SA 4.0 Wikipedia frequency data, the **generated assets** (`answers.txt`,
`answers_tiered.tsv`, `valid_guesses.txt` and their gzipped bundles) are
distributed under **CC BY-SA 4.0**, attributing Uzbek Wikipedia and the MUNIS
CC0 dictionary. This applies to the data files only; it does not affect the
licence of the application source code that reads them.

## Sources evaluated and REJECTED
| Source | Licence | Reason rejected |
|---|---|---|
| Leipzig Corpora Collection `uzb_wikipedia_2021` | CC BY-**NC** 4.0 | Non-commercial; app is monetised. (Frequency self-derived from Wikipedia instead.) |
| `u2b3k/uz-hunspell` (90k words) | **GPL-3.0** | Strong copyleft; unsuitable for bundling in a proprietary commercial app. |
| `kmashrab/uzbek-wordlist` (Debian `hunspell-uz`) | GPL | Copyleft **and** Cyrillic script (game is Latin). |
| `hermitdave/FrequencyWords` | MIT | No Uzbek data present in the repository. |
| `wooorm/dictionaries` | (various) | No Uzbek (`uz`) dictionary present. |

## Reproducing
```bash
cd tool/corpus
# 1. download the CC0 hunspell dictionary into <sources>/
#    (uz_Latn_UZ.dic, uz_Latn_UZ.aff from the release URLs above)
# 2. build the Wikipedia frequency table (~15-20 min; resumable, checkpointed)
python3 fetch_wiki_freq.py <sources>
# 3. build the assets + validation report
python3 build_corpus.py --sources <sources> --out out
```
